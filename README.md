## How it's built

A single hand-written `index.html` with no frameworks and no build step:

- HTML, CSS and vanilla JavaScript
- Interactive canvas node-graph in the hero, an animated code card, scroll reveals, card tilt and project filters
- Light and dark themes (follows your system setting, with a toggle)
- Responsive down to phone width, and respects `prefers-reduced-motion`
- Fonts from Google Fonts (Bricolage Grotesque, Source Sans 3, JetBrains Mono)

## Run locally

```bash
git clone https://github.com/Jayagna/jayagna.github.io
cd jayagna.github.io
python3 -m http.server 8000   # then open http://localhost:8000
```

Any push to `main` is published automatically by GitHub Pages.
